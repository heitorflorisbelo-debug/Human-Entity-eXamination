O que é o projeto? | Resumo

O projeto é um sistema de segurança para computadores, que tem como objetivo proteger os usuários contra ameaças cibernéticas, como vírus, malwares e ataques de hackers. O sistema utiliza uma combinação de técnicas de detecção de uso de memoria ram inutil e bloquear ameaças antes que elas possam causar danos ao computador do usuário.

O sistema tambem usa uma Inteligência Artificial para proteger um arquivo por possiveis hackers ou outras pessoas usando a maneira que a pessoa digita no computador

Novas coisas adicionadas

.Uma opção de aplicativo ao envez de extensão do chrome

.Configuração de uso de memória ram

.Verificador de arquivos: .bat, .py, .cpp, .exe para ver se são malwares.
