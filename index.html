O que é o projeto? | Resumo

O HEX é um sistema de segurança para computadores. Seu objetivo é ajudar a proteger o usuário contra acessos não autorizados e ameaças digitais.

O sistema analisa padrões de comportamento durante o uso do computador, como a maneira de digitar. Essas informações podem ajudar a identificar quando outra pessoa está usando o dispositivo.

O HEX foi pensado para funcionar localmente no próprio computador, sem depender de um servidor central para realizar essa verificação.

Novas coisas adicionadas

• Opção de aplicativo instalado no computador.

• Configuração do uso de memória RAM.

• Verificador de arquivos com extensões como .bat, .py, .cpp e .exe, para procurar possíveis sinais de malware.

Campanha publicitária

Nome da campanha: Seu computador reconhece você.

Slogan principal: Não basta saber a senha.

A campanha apresenta o HEX como uma camada extra de segurança. A ideia é mostrar que uma senha sozinha pode não ser suficiente e que o computador também pode analisar padrões de uso para ajudar a reconhecer o usuário.
